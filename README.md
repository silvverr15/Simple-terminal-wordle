# Simple-terminal-wordle
Мой первый тестовый проект на Python! Это простой консольный Wordle с базой из 240 слов (120 английских и 120 русских). Встроенного перезапуска игры пока нет, но он скоро появится!

**Особенности:**
- Можно выбрать язык — весь интерфейс игры и загаданное слово автоматически переключатся на выбранный язык (доступны английский и русский).
- Простая защита от опечаток.
